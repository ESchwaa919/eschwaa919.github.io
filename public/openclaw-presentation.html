What Is OpenClaw?

A 60-second explainer
  • Open-source autonomous AI agent, built by one developer as a weekend project (November 2025)
  • Connects to AI models (Claude, ChatGPT, Gemini) and runs on your own computer or server
  • You control it through messaging apps you already use — WhatsApp, Telegram, Slack, iMessage
  • Key differentiator: persistent memory — it remembers your habits and preferences across weeks and months
  • 100,000+ GitHub stars in under a week — one of the fastest-growing open-source projects in history

Slide 07

The Real Risks

⚠ Do Not Skip This Slide — What small business leaders must understand
  • Security is genuinely immature. Over 42,000 publicly exposed instances discovered by researchers.
  • Agents require access to your passwords, files, email, and messaging — a breach means full system compromise
  • Cisco found third-party "skills" performing data exfiltration without user awareness
  • Fake versions carrying trojans have already been distributed
  • Multiple companies have banned it outright on corporate devices

"Don't run it on your main computer — it's the wild west"

— Andrej Karpathy

Slide 08b

Does It Actually Learn?

Separating signal from mythology
✓ What it genuinely does
  • Chains tools autonomously — reads email, extracts data, updates spreadsheets, sends Slack alerts from a single goal
  • Uses persistent memory to improve — if an approach fails, it tries a different one and remembers what worked
  • On Moltbook, agents read other agents' workflows and adopt better strategies — knowledge transfer at scale
✗ What it does NOT do
  • Cannot modify its own neural network or invent capabilities beyond its tools
  • Not truly self-directed — remains goal-driven, tool-constrained, model-bounded
  • What looks like learning is memory-guided behavioural adaptation, not model retraining
◆ The real shift
  • Traditional software only does what you explicitly coded
  • Agent systems discover useful combinations of existing capabilities without explicit programming
  • Dynamic workflow composition instead of fixed workflows — genuinely new

"Instead of building fixed workflows, you deploy an agent and let it assemble them dynamically."
